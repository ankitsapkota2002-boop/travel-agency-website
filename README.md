# Travel Agency Website

A simple, clean travel agency website built with HTML, CSS, and JavaScript.

## About

This project was created to practice building a multi-section marketing website.  
It features destination highlights, responsive design, and basic interactivity — ideal for a student portfolio piece.

## Features

- Responsive layout
- Destination showcase sections
- Clean visual design with custom images
- Vanilla JavaScript interactions
- Semantic HTML structure

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```
├── index.html
├── style.css
├── script.js
├── image.png / japan.png / paris.png
└── README.md
```

## How to Run

```bash
git clone https://github.com/ankitsapkota2002-boop/travel-agency-website.git
cd travel-agency-website
# Open index.html in a browser
```
